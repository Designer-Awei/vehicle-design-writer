# 工作流

产品只保留一条文案创作链路。详细字段与验收见 [现行 PRD](./prd.md)。需求变更见 [ChangeLog.md](./ChangeLog.md)。

## 文案工作台

1. 在文案工作台新建或打开项目。打开后左上角显示标题，可切换项目。
2. **选题想法**：写清这期要回答什么；初步想法和事实补充可后补。
3. **视觉素材**：上传车型图，标主分析车型或其他车型，写上车型标签和比较说明。这里是当期图库，不做框选标注。
4. **设计分析**：左右对照看图（滚轮缩放、拖移、右上角切图），按 PFDBI 五维手写观察。
5. **初稿文案**：写正文；右侧补标题、内容类型和预期时长。字数按每分钟 250 字检查。
6. **保存 / 导出 / 导入**：点保存写入安装目录 `data/projects`；导出把当前项目文件夹打成 zip 安装包并自选地址；导入 zip 或旧文件夹。顶栏用未保存 / 未更新 / 已保存区分状态。

四个二级标签随时可切，不做阶段门禁。
