# Style DNA / 风格卡

> 产品入口已下线。现行写稿路径见 [prd.md](./prd.md)。下文只保留旧提取原则，供以后若再积累风格时对照，不再作为实现依据。

默认按**一篇源文案**提取一张预览风格卡，包含：

- 作者（可改）
- 内容类型（预览卡标签：车型解读 / 设计知识 / 设计观点 / 设计回顾 / 新车热点 / 设计跨界）
- 不超过 20 字的风格简介（提取时自动生成，供卡片展示和创作选卡）
- 语言与语气摘要
- 结构模板（这篇口播实际怎么分段，不按内容类型拆多份）
- 示例句式（few-shot 短片段）

人确认后才入库。已入库风格卡供文案创作选用；未确认的预览卡不能写稿。

多篇同博主聚合仍可作为后续“合并风格卡”能力，不是默认入口。

提取时必须区分：

- 主题（这期在讲什么）
- 汽车专业知识（术语本身）
- 作者个人风格（如何组织这些术语）

指标在 UI 中标注为“AI 分析指标，用于辅助理解风格特征。”演示数据带 `DEMO DATA`，不是真实博主文案。
