# 文案工作台｜链路展示说明

> 把本文完整发给绘图用的 GPT。请它只根据本文画图，不要补造功能，不要改中文用词。

## 0. 给绘图模型的总指令

请根据下文，用**简体中文**产出一套同事也能看懂的流程图。不要写成开发架构图，不要出现数据库表名、IPC、Zod、Electron 等实现词。

**必须产出的图（按顺序，每张都要有标题）：**

1. 产品总览：工作台四个步骤
2. 打开项目后的页面结构（一级菜单 + 纵向二级标签）
3. 设计分析页怎么对照看图、怎么写 PFDBI
4. 初稿页的正文和辅助检查
5. 人负责什么（建议泳道图，Agent 侧标明本期不做自动写稿）

**绘图要求：**

- 风格：扁平、深色或中性办公风均可，但同一套图配色要统一
- 用圆角矩形表示步骤
- **人**用一种颜色；不要画风格库、风格卡、矩形标注
- 每条箭头写短标签
- 一张图信息不要过密

**不要画的：**

- 风格库、上传文稿抽风格、选手动风格卡
- 框选标注、自动视觉观察、自动生成 PFDBI、一键生成初稿
- 登录、权限、云同步
- 代码目录、接口列表

## 1. 一句话介绍产品

这是给汽车设计内容团队用的桌面工具。同事在工作台一篇篇写口播：先想清楚讲什么，再对照车图写下设计判断，最后自己写初稿并按时长核对字数。风格靠写成稿积累，不单独建风格库。

---

## 2. 图 1｜产品总览

**标题：** 四个步骤写完一期

从上到下：

1. 选题想法
2. 视觉素材
3. 设计分析
4. 初稿文案

白话：没有旁路。打开项目就按这四页写。

---

## 3. 图 2｜页面结构

**标题：** 先选项目，再进四步

- 左侧一级菜单：首页、文案工作台、设置
- 文案工作台先出项目列表
- 点开项目后：顶栏左侧是标题（可切换项目）；内容区左侧是纵向四个二级标签

---

## 4. 图 3｜设计分析

**标题：** 对照看图，人写 PFDBI

- 上方两个预览区，标「图 1」「图 2」
- 每个预览区右上角可切换本期已导入的图
- 滚轮缩放，左键拖移
- 下方五个标签：P 比例姿态 / F 型面 / D 细节 / B 品牌 / I 创新
- 选中标签后在文本框写人眼观察

---

## 5. 图 4｜初稿页

**标题：** 正文加检查，不自动成稿

- 左侧大文本框写初稿，左下角显示当前字数
- 右侧：文案标题、内容类型（六类写全）、预期时长
- 脚注：一分钟按 250 字估算目标字数

内容类型必须写全：车型解读、设计知识、设计观点、设计回顾、新车热点、设计跨界。

---

## 6. 关键用词（必须沿用）

- 文案工作台、选题想法、视觉素材、设计分析、初稿文案
- 主分析车型、其他车型、车型标签、比较说明
- PFDBI、事实补充、初步想法
- 不要出现：风格库、风格卡、矩形标注、视觉观察按钮、生成初稿
