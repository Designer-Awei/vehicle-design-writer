# 产品逻辑

系统拆成四层，都在文案工作台里完成：

1. **视觉证据**：车型参考图只回答“看到了什么”。角色、车型标签和比较说明帮助对照，不做框选标注。
2. **内容逻辑**：人对照看图后写下 PFDBI，回答“讲什么、为什么这样判断”。
3. **事实素材**：用户粘贴的参数、发布会原话、报道、设计历史，只回答“还可以引用哪些已提供的事实”，系统不联网核实。
4. **成稿约束**：内容类型、预期时长和每分钟 250 字，用来检查初稿节奏。

文案风格靠工作台一篇篇写来积累，本期不单独维护风格库，也不选手动风格标签。

禁止把没看见的型面写成已确认事实。禁止把事实补充里没有的参数写成官方数据。
