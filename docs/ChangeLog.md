# ChangeLog

本文是本项目**需求与产品变更的事实源**。实现、README、现行 PRD 若与本文冲突，以较新的 ChangeLog 条目为准，并应回写到 [prd.md](./prd.md)。

日期均为实际落地或定稿的日期。条目按时间倒序。

## 2026-09-14

### 项目保存、状态灯与安装包导出

- 默认路径始终跟**当前安装目录**走：`安装目录/data/projects`。只有用户主动「选择目录」才记住自定义路径；「恢复默认」会清掉记忆，不会把某次便携包路径写死进设置。
- 新建文案、上传参考图都只在内存里。点**保存**后才在项目库按约定格式新建文件夹（`参考图/` + `项目.json`），相当于保存项目。上传不再另复制一份图到 `data/images`。
- 顶栏和列表用短状态词 + 颜色灯：未保存（金）、未更新（橙）、已保存（绿）。
- **导出**改为把当前项目文件夹打成 zip 安装包，弹出另存为让用户自选地址。未保存时会先写入项目库再打包。
- **导入**可选择 zip 安装包或旧版项目文件夹，复制进当前项目库；上一版多个 txt 仍可读。

### 项目导入 / 导出

- **导出**会弹出选目录，默认路径是设置里的项目导出目录（默认安装目录 `data/exports`）。选好后按标题新建约定格式的文件夹，不自动打开。标题冲突时追加时间戳。
- **导入**只选择用户已有的项目文件夹，登记到软件里查看：参考图继续用原路径，不另建目录、不复制一份。删除项目时也不删这个原文件夹。
- 导出包格式：`参考图/` + 一份 `项目.json`（选题、想法、事实、PFDBI、初稿、时长和图片索引都在清单里）。上一版多个 txt 仍可导入。
- 设置页「存储」可改参考图目录和导出目录，均可恢复默认、打开文件夹。
- 项目列表可导入；列表行和工作台顶栏可导出。导出成功后只提示路径。

### 参考图存储目录

- 上传参考图仍会**复制一份**，不依赖用户原路径。
- 默认复制到安装目录下的 `data/images/{项目ID}/`（开发时是项目根目录的 `data/images`）。
- 设置页「参考图存储」可改目录、恢复默认、打开文件夹。已导入的图仍读当时的复制路径；新上传进当前目录。导入项目不会再复制到这里。

### Windows 安装包

- 安装程序改为 NSIS 向导，可自选安装路径（对齐 Fast Hardware：非一键安装、允许改目录、可提权）。
- 使用自制图标（汽车前脸线框），不再用 Electron 默认图标。
- 打包完成后 `dist` 只保留便携文件夹、安装程序 exe 和增量更新用的 `latest.yml`；不保留 zip / 7z、`win-unpacked` 原名和构建调试文件。

### 砍掉风格库，工作台改成四步写稿

- 侧栏、路由和首页不再提供风格库。文案风格先靠工作台一篇篇写来积累，不再单独抽卡、选卡。
- 文案工作台选中项目后进入纵向二级标签：选题想法 → 视觉素材 → 设计分析 → 初稿文案。左上角显示当前标题，可切换项目。
- 去掉生成前选手动风格标签 / 风格卡的过程。
- 视觉素材页保留上传、主分析/其他车型、车型标签、比较说明；去掉框选标注。这一页只当当期视觉素材库。
- 设计分析页改为双图对比预览（右上角切已导入图片，滚轮缩放、左键拖移），下方按 PFDBI 标签手写观察，不再跑视觉观察 / PFDBI 模型。
- 初稿文案页只提供正文框和辅助检查：文案标题、现有 6 类内容类型、预期时长（按每分钟 250 字估目标字数）。正文左下角显示当前字数。
- 改选题、时长、事实补充或保存正文时，不再清空已写的 PFDBI / 初稿，也不再每次保存都记一版。

### 结构模板与默认模型

- 按篇提取只抽出 **1 份**结构模板，反映这篇口播实际怎么分段；内容类型只作为预览卡标签，不再按六类各生成一份模板。
- 根目录 `.env` 里若仍是上一版 DeepSeek-V4-Flash，会当成旧默认并切到 `Qwen/Qwen3.5-27B`。

### 默认文字模型

- 文字模型默认改为 `Qwen/Qwen3.5-27B`。仍停在上一版内置 DeepSeek-V4-Flash 的安装会自动切过去；设置页或 `.env` 里手动指定过的其它模型保持不变。

### 风格卡简介

- 已入库风格卡不再使用空白「备注」。提取时自动抽出不超过 20 字的风格简介，展示在卡片上，并作为工作台 Agent 匹配风格卡的依据。人仍可事后改这句简介。

### 提取失败原因与入口收口

- 上传文稿失败时，任务列表展示 SiliconFlow 的真实原因（例如账户余额不足），不再一律写成“分析失败或超时”。
- 去掉风格库「高级：文件夹聚合」按钮和顶栏入口。

## 2026-09-11

### 窗口与工作台崩溃修复

- 打开演示项目的「准备上下文」时，旧 PFDBI JSON 缺比较字段会把整页卸掉，看起来像黑屏且侧栏也点不了。读取时补齐缺字段，页面出错时保留侧栏。
- Windows 顶栏改为 Cursor 同款做法：深色底、浅色字、Electron 图标和 File / Edit / View / Window / Help；右侧仍用系统最小化 / 最大化 / 关闭。

### P1 / P2 / P3 落地

- 风格库默认改为上传任意数量 txt/md/rtf，一篇文档一个后台提取任务；完成后打开预览卡，人确认才入库。旧的文件夹聚合降为高级入口。
- 生成初稿时 Agent 从已入库风格卡中自选（或明确改用中性结构）；人手选改为覆盖项，并展示选了哪张、为什么。
- 工作台收成「准备上下文」与「文案编辑」两屏。无参考图也可运行 PFDBI，但必须声明证据不足。

### 文档与仓库整理

- `docs/` 改为「现行文档 + archive 历史稿」：现行规格是 `prd.md`（原 V3），V1 原始 Goal Prompt 与 V2 工作流 PRD 移入 `docs/archive/`。
- 根目录增加 `docs/ChangeLog.md`，作为需求变更记录。
- 多次 Electron 端到端跑出来的隔离 `userData`（原 `.e2e-user-data*`）集中到 `archive/e2e-user-data/`。`.vscode` 是编辑器配置，不是测试用例，留在仓库根目录。

### 双链路产品定稿（V3）

- 产品拆成 **风格配置** 与 **文案创作** 两条链路，只在生成初稿时用「已入库风格卡」汇合。
- 风格配置目标路径：上传任意数量文稿 → 按篇后台队列提取 → 预览风格卡 → 人确认后入库。旧的「先建档案再选文件夹聚合」降为高级入口。
- 文案创作目标路径：人提供选题、初步想法、参考图与标注、PFDBI、事实补充；Agent 选风格卡并写初稿；人审阅导出。
- 给同事画图的说明见 `docs/workflow-diagram-brief.md`。

### 事实补充（P0，已实现）

- 工作台成稿设置增加「事实补充」文本区，与「初步想法」分开。
- 用于粘贴新车参数、发布会原话、媒体报道、设计历史等，作为初稿素材，不是文风。
- 写入 `projects.facts`；生成 Base Draft 时纳入提示词；修改后会使已生成稿件失效。

## 2026-09-10

### 风格提取体验与稳健性

- 提取等待层：分步进度 + 汽车设计冷知识轮播；冷知识区域固定两行高度。
- 结构模板 / 例子兼容模型常用中英文字段名，并去重「未命名模板」重复骨架。
- 提取改为分片并行（单篇分析、DNA 切片、按内容类型出模板），单片失败不再整单作废。
- SiliconFlow 超时改为中文说明；单次请求超时缩短，避免卡死 120 秒后整条失败。

### 风格库交互

- 风格详情页去掉顶栏「重新提取」和「删除风格」。
- 删除风格只保留风格列表卡片右侧按钮。
- 重新提取只保留「样本文档」区域内的按钮。

### 创作链路 V2（已落地，细节见 archive）

- 风格创建：选文件夹成功才建档，取消不留空档案。
- 工作台串行：参考图与标注 → 视觉观察 → PFDBI → 成稿设置 → 编辑导出。
- 图片角色改为「主分析车型 / 其他车型」，比较关系写在比较说明里。
- 可视化矩形标注；上游变更会使下游产物失效。
- Windows 深色标题栏与内容区统一。
